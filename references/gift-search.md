# 礼物双层检索方法论

礼物推荐分两层：**外部检索**（找「同类人群喜欢什么」）与**人物代入推演**（「如果我是 TA 我想要什么」）。两层缺一不可，检索结果必须经过画像过滤，输出固定 5 个备选。

## 第一层：外部检索

### 通道优先级

1. **小红书**（首选，送礼种草内容最对口）：云端浏览器登录小红书 → 按搜索词搜索 → 阅读种草笔记正文与评论区，提取真实推荐与避雷。
2. **通用搜索**：补全小红书缺失的品类（如数码、户外装备评测、订阅服务）。
3. **垂直站点**（按需）：如数码（什么值得买）、户外（骑行/露营社区）、咖啡（评测文）。

### 搜索词构造（禁止只搜「生日礼物」一层）

搜索词 = 人群特征 + 场景，分 4 步：

| 步骤 | 输入 | 示例（女/28/咖啡） |
|---|---|---|
| 1 人群搜索 | 性别 + 年龄段 + 关系 + 爱好 | 「28 岁 女生 咖啡 生日礼物」 |
| 2 垂直深挖 | 爱好细分词 + 品类词 | 「手冲咖啡 入门 装备 推荐」「咖啡豆 订阅 测评」 |
| 3 分类校准 | 关系分类 + 场景词 | 「送女友 生日 心意 礼物」「送爸爸 实用 礼物」 |
| 4 价格过滤 | `budget_range` | 过滤超预算与过廉价选项 |

### 检索纪律

- 每条 query 至多一次检索，避免重复搜索同一信息。
- 小红书未登录导致内容受限时，先引导使用者完成登录，**不要**静默改用通用搜索替代（登录态是可配置依赖）。
- 记录来源链接，输出时附上（笔记/文章/商品页）。

## 第二层：人物代入推演

外部检索给出「大众答案」，代入推演给出「TA 的答案」。

### 推演步骤

1. 读取该人完整画像（性别/年龄/爱好/角色/预算/避坑备注）。
2. 切换视角自问：**「如果我是 {name}，{age} 岁、{gender}，喜欢 {interests}，生日那天我最想要什么？」**
3. 从爱好延伸场景：不只送「爱好本体」，送「升级件/耗材/体验/周边」——爱咖啡的人缺的不是豆，可能是手冲壶、称、订阅卡。
4. 用关系分类校准温度：伴侣→心意与纪念意义；家人→实用与耐用；朋友→新奇与趣味。
5. 对照 `gift_notes` 剔除送过的、忌讳的。

### 代入推演的输出要求

- 5 个备选中**至少 1 个**来自代入推演层（搜索里没有、但画像推得出），并标注「TA 会喜欢因为……」。

## 输出格式：5 个备选清单

每个备选固定包含：礼物名称、**最优惠价格+对应平台**、真实优缺点（≥2优≥2缺）、避坑建议、选择理由、来源链接。

```
🎁 给【张三】的 5 个礼物备选（预算 200-500）

1. 手冲咖啡壶套装（最优惠：天猫旗舰店 ¥320；京东 ¥399）
   优点：TA 爱手冲，现用入门款可升级中段位；……
   缺点：……
   避坑：……
   理由：画像备注 TA 提过想换壶
   来源：小红书笔记 xxx / 什么值得买评测
```

## 质量检查（输出前自查）

- [ ] 5 个备选齐全，价格在预算内或明确标注超预算原因
- [ ] 每个备选附**最优惠价格+对应平台**（具体数字+具体渠道，不是"约几百元"）
- [ ] 每个备选附**真实优缺点**（≥2优≥2缺，来自真实用户测评）
- [ ] 每个备选附**避坑建议**（具体踩雷点，不是空话）
- [ ] 每个理由引用了画像里的具体信息（爱好/角色/备注），无空泛「很适合」
- [ ] 至少 1 个来自代入推演层
- [ ] 已排除 `gift_notes` 中送过的/忌讳的
- [ ] 每个备选附来源链接可溯源
- [ ] **禁止凭模型记忆直接推荐**：必须先检索再写，没搜过的产品不出现
