# 使用示例（Usage Example）

本文件演示：假设你已装好本 skill、填好人物画像（参考 `assets/sample-profile.json`），月度扫描触发时会发生什么。

## 假设场景

- 今天：2026-09-01（周二）
- 画像里有3个人（来自 `sample-profile.json`）：
  - 小明（朋友/男/骑行咖啡）：2026年生日 2026-06-16 → 已过
  - 小红（伴侣/女/摄影烘焙）：2026年生日 2026-09-25 → 24天后
  - 张阿姨（家人/妈妈/广场舞）：2026年生日 2026-04-25 → 已过

## ReAct 检测基准执行

**检查点1**：画像 JSON 可读，3人都在。✅
**检查点2**：小红的 `annual_birthday["2026"]` = `{"date":"2026-09-25","weekday":"周五"}`，age=28，zodiac_sign=天秤座。✅
**检查点3**：days_left = 24 → 0≤24≤60，进入候选池。小明/张阿姨已过，跳过。✅
**检查点4**：小红 `gift_reminded_year` 为空 → 保留。✅
**检查点6**：对小红做真实检索，输出5个备选。✅

## 飞书推送（markdown加粗版，发到 notify.feishu_chat_id）

```
**🎂 生日提醒：小红**
**9月25日（周五）生日 · 还有24天 · 伴侣档**

优点：可预览可删、胶片模拟滤镜、蓝牙连手机
```

## 邮件推送（HTML版，发到 notify.email_to）

主题：`【生日提醒】小红 9月25日（周五）生日，还有24天`

正文（HTML）：
- 标题 `<h3><b>🎂 小红生日提醒</b></h3>` 加粗加大
- 5个备选完整版：每个含优缺点（≥2优≥2缺）、避坑、最优惠价格+平台、来源链接
- 末尾写回：`gift_reminded_year = "2026"`（至少一个通道成功才写）

## 写回 JSON

推送成功后，小红的画像里追加：
```json
"gift_reminded_year": "2026"
```
这样今年9月1号到明年1月1号的月度扫描不会再重复推小红。

**明年1月1号**触发时，开年分支自动：
1. 把小红的农历生日"八月十五"换算成2027年公历日期
2. 更新 age=29
3. 重置 `gift_reminded_year = ""`
4. 正常扫描未来60天

## 你不需要做什么

- 不用一人建一个闹钟
- 不用记农历转公历
- 不用想礼物（AI 帮你搜真实评测）
- 不用怕漏（每月1号扫，飞书+邮箱双推送）
