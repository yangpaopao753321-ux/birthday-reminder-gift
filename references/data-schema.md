# 画像数据 Schema 与校验规则

画像数据是唯一事实来源（single source of truth）。所有流程从画像文件读取，写入前校验。

## 文件结构

```json
{
  "schema_version": "1.1",
  "updated_at": "2026-09-23",
  "people": [
    {
      "name": "张三",
      "category": "家人",
      "family_role": "爸爸",
      "gender": "男",
      "birth_year": "1970",
      "birthday_type": "lunar",
      "lunar_birthday": "八月十五",
      "lunar_leap_month": false,
      "zodiac_sign": "天秤座",
      "age": 56,
      "interests": ["骑行", "咖啡"],
      "gift_notes": "去年送过保温杯，对电子产品兴趣一般",
      "budget_range": "200-500",
      "annual_birthday": {
        "2026": "2026-09-18",
        "2027": "2027-09-08"
      }
    }
  ]
}
```

## 字段定义

| 字段 | 必填 | 说明 |
|---|---|---|
| `schema_version` | 是 | 固定 `"1.1"`；升级时做字段迁移 |
| `updated_at` | 是 | 最近一次画像更新的日期，开年任务写回时刷新 |
| `name` | 是 | 姓名，唯一标识（重名须加备注区分） |
| `category` | 是 | 枚举：`家人` / `朋友` / `伴侣` |
| `family_role` | 条件 | `category=家人` 时必填：妈妈/爸爸/兄弟/姐妹等；其他分类可留空 |
| `gender` | 是 | 枚举：`男` / `女` / `其他` |
| `birth_year` | 是 | 出生年份（4 位数字），用于农历换算与年龄计算 |
| `birthday_type` | 是 | 默认 `lunar`（农历）。`solar` 仅作扩展保留，流程按农历为主 |
| `lunar_birthday` | 是 | 农历月+日，如 `"八月十五"`；`solar` 时为 `"MM-DD"` |
| `lunar_leap_month` | 否 | 是否闰月生日，默认 `false`；仅 `lunar` 生效 |
| `zodiac_sign` | 是 | 星座，由出生年首个公历日期（月日）推算，终身不变；首次建档自动生成 |
| `age` | 是 | 年龄，每年开年更新 |
| `interests` | 是 | 爱好数组，至少 1 条；每年可追加，**追加不覆盖** |
| `gift_notes` | 否 | 送礼备注：送过什么、忌讳、偏好，供避坑 |
| `budget_range` | 否 | 预算区间如 `"200-500"`；缺失时默认按分类给建议档 |
| `annual_birthday` | 是 | 对象：年份 → `{date: "YYYY-MM-DD", weekday: "周X"}`；开年任务逐年追加，weekday 由 date 算 |
| `gift_reminded_year` | 否 | 上次已推送礼物提醒的年份（如 `"2026"`）；月度扫描去重用，开年任务自动重置为空 |

## notify 字段（顶层）

| 字段 | 必填 | 说明 |
|---|---|---|
| `feishu` | 是 | 是否开飞书通道：`true`/`false` |
| `feishu_chat_id` | 条件 | `feishu=true` 时必填；飞书接收消息的 chat_id（`oc_xxx`），用 `lark-cli im +chat-list` 查 |
| `email` | 是 | 是否开邮箱通道：`true`/`false` |
| `email_to` | 条件 | `email=true` 时必填；收件邮箱地址 |

## 星座推算规则

星座**终身不变**，只看**出生那年**的公历月日，不随每年农历换算结果变化。

算法：用 `birth_year`（出生年）+ `lunar_birthday`（农历生日）换算出该年的公历日期，取其**月-日**查下表。注意不是用"今年"的公历日期。

| 公历日期（月-日） | 星座 |
|---|---|
| 03-21 ~ 04-19 | 白羊座 |
| 04-20 ~ 05-20 | 金牛座 |
| 05-21 ~ 06-21 | 双子座 |
| 06-22 ~ 07-22 | 巨蟹座 |
| 07-23 ~ 08-22 | 狮子座 |
| 08-23 ~ 09-22 | 处女座 |
| 09-23 ~ 10-23 | 天秤座 |
| 10-24 ~ 11-22 | 天蝎座 |
| 11-23 ~ 12-21 | 射手座 |
| 12-22 ~ 01-19 | 摩羯座 |
| 01-20 ~ 02-18 | 水瓶座 |
| 02-19 ~ 03-20 | 双鱼座 |

## 校验规则

- `interests` 为空、`budget_range` 非法格式、`lunar_birthday` 无法被万年历确认 → 先向使用者补齐/确认，禁止编造。
- `annual_birthday[当年]` 与使用者确认的当年生日不一致时，以万年历/换算结果为准并说明差异。
- 新增人物：追加到 `people` 数组，不改变既有条目（增量修改）。
- 每年追加爱好：只向 `interests` 追加新元素，保留旧值（可留「新增于 YYYY」备注）。

## 错误处理

| 错误 | 处理 |
|---|---|
| JSON 解析失败 | 定位行号修复；无法修复时从 `.bak` 恢复并告知使用者 |
| 字段缺失/非法 | 列出缺失字段，询问使用者补齐后再继续，不静默跳过 |
| 换算失败（如闰月歧义） | 参照 lunar-conversion.md 边界处理，仍不确定则向使用者确认 |
