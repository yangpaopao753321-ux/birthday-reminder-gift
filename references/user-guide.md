# 使用说明（User Guide）

这份文档写给**使用者**（不一定是创建者）：说明 birthday-reminder-gift 是什么、怎么开始用、日常怎么维护、常见问题怎么处理。

## 这个技能做什么

管理你家人/朋友/伴侣的生日画像（**生日按农历记录**），全自动运行：
1. **每月1号扫描一次**：把每个人的农历生日换算成当年公历日期，扫描未来60天内要过生日的人
2. **命中即推送**：按距离生日天数分档（当天 / 1-15天紧急 / 16-60天预告），推送到飞书+邮箱
3. **礼物推荐**：按画像（性别/年龄/关系/爱好）联网搜真实评测，给出5个备选（含优缺点/避坑/最优惠价格+平台）
4. **去重**：每人每年只推一次，不会重复打扰
5. **自动开年**：如果1月1号触发扫描，先自动换算全年生日再扫描，不用单独建任务

## 开始使用（三步）

### 第 1 步：提供人物信息（由 AI 引导你逐项填写）

你只需要用聊天的方式告诉 AI 每个人的信息，AI 负责整理进数据库。每人大致提供这些：

| 信息 | 必填 | 说明 |
|---|---|---|
| 姓名 | 是 | 重名需加备注区分 |
| 关系分类 | 是 | 家人 / 朋友 / 伴侣 |
| 家人角色 | 家人必填 | 妈妈、爸爸、兄弟、姐妹等 |
| 性别 | 是 | 男 / 女 |
| 出生年份 | 是 | 用于算年龄和星座 |
| **农历生日** | 是 | **必须填农历**（如「八月十五」）；闰月生日要说明是过闰月那天 |
| 爱好 | 是 | 至少 1 个，越多越准（如骑行、咖啡、摄影） |
| 送礼备注 | 否 | 送过什么、忌讳什么、偏好什么 |
| 预算范围 | 否 | 如 200-500，不填则按分类给建议档 |

> 注意：生日一定是**农历**。如果你只知道公历生日，告诉 AI 公历日期和出生年份，由 AI 换算成农历确认后再记录。

### 第 2 步：AI 校验并落库

- AI 用换算脚本/万年历核对每个农历生日，生成星座、年龄，写入画像 JSON 文件（默认 `birthday_profiles.json`，在你的项目目录）
- 你会收到一份「已录入人物清单」回执，确认无误后进入下一步

### 第 3 步：配置推送 + 挂月度扫描任务

- 确认推送通道：飞书消息（需要提供飞书 chat_id，用 `lark-cli im +chat-list` 查到）、邮箱（需要提供收件地址）
- AI 创建**1个**定时任务「生日月度扫描」：每月1号10:30执行，自动完成换算+扫描+推送+去重
- 完成后告诉你首次触发时间；新用户从下个月1号开始就能收到推送，不用等明年1月1号

## 邮箱通道怎么打通（腾讯 Agent 邮箱）

发件不需要你操作（Agent Mail 用已绑定账户代发），但**首次需要完成邮箱的开通与授权**，否则邮件通道不可用。以下为腾讯 Agent 邮箱的标准开通流程，约 5-10 分钟。

### 一、开通流程

**第一步：创建邮箱地址**
1. 打开官网 https://agent.qq.com/ ，**微信扫码登录**（需完成实名认证）
2. 页面提示「暂未创建邮箱地址」时点「立即创建」
3. 设置邮箱前缀：字母开头、6-18 位、只能用字母和数字，确认后生成 `前缀@agent.qq.com`
4. 注意：每个微信号目前最多可创建 **2 个**邮箱地址，每个地址仅能修改一次

**第二步：接入你的 Agent（两种方式选一）**
- **自动接入（推荐）**：在支持的 Agent 对话窗口里直接发送这句官方提示词：
  > 请阅读 https://agent.qq.com/doc/cli-setup.md 文档，按照步骤为我安装并配置 Agent Mail CLI。
- Agent 会自动安装 CLI 和 Skill，并返回一个**授权链接**，点击完成授权即可

### 二、配置到本技能

授权完成后，在初始化「第 3 步」告诉 AI：
- 你的**收件邮箱地址**（通常是刚创建的 `前缀@agent.qq.com`，也可以是其他常用邮箱）
- AI 会将收件地址写入配置，此后每次提醒同时推送飞书 + 该邮箱

### 三、过期/失效处理

- 邮箱授权有时效，过期后发送会失败；此时系统**不反复重试**，提醒照常走飞书消息，不丢失
- 收到「请重新授权 Agent Mail」提示后，按上面的第二步重新发起授权即可恢复

## 日常使用

- **不需要你做任何事**：每月1号自动扫描+推送，全自动运行
- **随时加人/改信息**：告诉 AI「帮我把 XX 加进画像」或「XX 最近迷上露营了」，AI 更新 JSON，任务逻辑不用动
- **想看全年安排**：让 AI 读取画像文件，输出当年每人公历生日和星期几清单
- **为什么是60天窗口**：每月1号扫未来60天，保证1号当天生日的人也能提前收到提醒，有充足时间准备礼物

## 常见问题

**Q1：农历生日每年公历日期不一样，会算错吗？**
不会。每月1号触发时自动用当年农历年份换算，结果写入画像的 `annual_birthday` 字段（含星期几），并输出清单供你核对。

**Q2：Agent Mail（邮箱授权）过期了怎么办？**
邮箱授权有时效，过期后邮件会发送失败。处理方式：
1. 系统检测到失败后不会反复重试，提醒**照常走飞书消息**，不会丢
2. 你会收到「邮箱授权已过期，请重新授权 Agent Mail（QQ 邮箱）」的提示
3. 重新授权后，邮件通道自动恢复

**Q3：小红书搜索要求登录，过期了怎么办？**
首次使用需在云端浏览器登录小红书；登录过期后提醒功能不受影响，只是礼物检索会改用通用搜索，直到你重新登录。

**Q4：换了设备 / 想给别人用怎么迁移？**
把画像 JSON 文件 + 本技能文件夹一起复制过去，在新环境重新走一次「第 3 步配置推送 + 挂月度扫描任务」即可。技能文件夹内不含任何人的真实画像数据（示例均为化名）。

**Q5：画像文件想自己编辑怎么办？**
直接用文本编辑器打开 JSON 修改，或让 AI 修改。修改前 AI 会自动备份（`.bak`）；字段格式见 `references/data-schema.md`。

## 数据与隐私

- 你的画像数据只存在**你的 JSON 文件**里，不写入任务、不随技能分发
- 技能打包给别人时只含框架、模板、脱敏示例（化名+虚构爱好）
- `references/project-log.md` 是开发记录，分发前建议删除
